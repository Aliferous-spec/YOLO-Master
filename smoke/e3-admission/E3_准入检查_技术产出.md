## 2. 三类路由的字段现状

- MoE：`ExpertUsageTracker.usage_stats` 按 router 输出专家 hits / weighted_sum；
  `MoELayerDiagnostic`（`ultralytics/nn/modules/moe/diagnostics.py`）提供 dominant expert 等诊断字段
- MoT：`expert_usage`（直接张量）以及 `scene_aware` / `scene_stats` / `scene_bias` 等场景字段
- Latent：`last_routing_snapshot`（36 个字段），含 `value_fusion_mode` / `value_fusion_weights`，
  并区分 `top_k` / `training_top_k` / `inference_top_k`

三类模块的路由语义不同：MoE 偏“离散选择”，MoT 带场景条件，Latent 偏“连续融合”。
统一采集层需要做字段适配并携带范式标记；当前只完成了字段对照，未实现代码。

## 3. 统一字段映射（设计草案，未实现）

以下对照表是候选字段映射，**不是已实现或已冻结的 schema**：

| 统一字段（拟） | MoE 来源 | MoT 来源 | Latent 来源 | 说明 |
| --- | --- | --- | --- | --- |
| `num_experts` | `num_experts` | `num_experts` | `num_experts` | 三类原生都有，可直接对齐 |
| `top_k` | `top_k` | `top_k` | `top_k` / `training_top_k` / `inference_top_k` | Latent 区分训练/推理两套 top_k，需在统一层归一 |
| `expert_usage` | 由 `ExpertUsageTracker.usage_stats` 聚合 hits/weighted_sum 推导 | `expert_usage`（直接张量） | `expert_usage` | 张量形状需统一为 `[num_experts]` 浮点列表 |
| `aux_loss` | 通过 `routing_protocol.RoutingAuxPublisher` 获取 | `aux_loss` | `aux_loss` | 三类天然共有的字段 |
| `dominant_expert` / `dominant_share` | `MoELayerDiagnostic` 原生支持 | 需从 `expert_usage` 现算 | 需从 `expert_usage` 现算 | MoT/Latent 缺此字段 |
| `collapse_flag` | 原生支持 | 需自定义阈值判断 | 需自定义阈值判断 | 阈值建议先沿用 MoE 侧 0.8 |
| `scene_context` | 无 | `scene_aware` / `scene_stats` / `scene_bias` | 无 | MoT 独有字段 |
| `value_fusion_*` | 无 | 无 | `value_fusion_mode` / `value_fusion_weights` | Latent 独有字段 |

设计倾向：采用“公共字段 + 各类专属字段”两层结构，并带 `routing_paradigm` 标记，
而不是单一扁平表（Latent 字段数明显多于 MoE/MoT，扁平表会有大量空值列）。
以上均为设计讨论，不是已交付代码。

## 4. hook 开销测量方法

脚本：`scripts/measure_routing_hook_overhead.py`

- 方法：同一模型、同一批输入，分别统计“开启 hook 采集”与“关闭 hook”两种状态下的
  多次前向总耗时；只计前向 + hook 回调时间，不含数据加载与后处理
- 验收口径：额外开销占比 = (开 hook 耗时 - 关 hook 耗时) / 关 hook 耗时，目标 < 10%
- 说明：本次测量数值未单独归档日志，可自行复跑验证；脚本默认参数为 50 次前向、
  640×640、`ultralytics/cfg/models/master/v0_9/det/yolo-master-n.yaml`

## 5. 未验证事项

- Latent 字段数（36）多于 MoE/MoT，统一表会有大量空值列——两层结构是设计倾向，未实现

- MoE 走 `ExpertUsageTracker` hook，MoT/Latent 走 `last_routing_snapshot`，
  两条采集路径尚未统一
